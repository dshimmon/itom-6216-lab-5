# QuoteSide

ITOM 6216 Lab 5. QuoteSide compares two fictional commercial property insurance quotes for Trinity Print House, a fictional Dallas print shop. The demo uses plain HTML, CSS, and JavaScript. The comparison and the rule-based quote assistant read the same data in `assets/site.js`. The assistant runs in the browser with no API, backend, or credentials.

## Run or deploy

Open `index.html` locally. For GitHub Pages, put the contents of this folder at the root of a public repository and choose **Settings → Pages → Deploy from a branch → main → /(root) → Save**. The layout and assets use relative URLs, so the same files work at a project URL. See [GitHub’s instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Landing page video

`assets/quote-demo.mp4` is the supplied Gemini-generated quote scan, approximately 10.03 seconds long. It highlights the business contents and business income limits from the same fictional quotes used in the comparison table. The poster is a frame from the clip that shows both highlighted rows. The video autoplays muted and loops inline, with a pause control and support for reduced motion.
