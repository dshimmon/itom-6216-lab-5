# QuoteSide

ITOM 6216 Lab 5. QuoteSide compares two fictional commercial property insurance quotes for Trinity Print House, a fictional Dallas print shop. The demo uses plain HTML, CSS, and JavaScript. The comparison and the rule-based quote assistant read the same data in `assets/site.js`. The assistant runs in the browser with no API, backend, or credentials.

## Run or deploy

Open `index.html` locally. For GitHub Pages, put the contents of this folder at the root of a public repository and choose **Settings → Pages → Deploy from a branch → main → /(root) → Save**. The layout and assets use relative URLs, so the same files work at a project URL. See [GitHub’s instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Video requirement

The included `assets/quote-demo.webm` is a five-second motion graphic rendered from code. It demonstrates the concept and the intended video playback. It is not a clip from an AI video generator.

For the assignment’s AI video requirement, export a roughly five-second clip from an AI video generator. Save the MP4 as `assets/quote-demo.mp4`, then change the `<source>` and download link in `index.html` to that file and set the source type to `video/mp4`. Keep `autoplay loop muted playsinline` on the video. If the generator exports WebM, replace `assets/quote-demo.webm` directly.

Suggested video prompt:

> Five-second silent motion graphic, 16:9. Two cream and pale-blue commercial property quote documents on a deep navy background slide apart and transform into aligned side-by-side comparison columns. The documents simplify into bold rows for annual premium and wind and hail deductible. Use a clean, flat editorial style, a celadon accent, a locked camera, and no real carrier logos. Hold the comparison briefly, then ease back into the starting composition for a smooth loop.
